## 1. ХУК (0–3 сек) — «звук в уши»

- **Задача:** на самом входе резкий whoosh/impact «в уши», чтобы зацепить.
- **Слой SFX:** `sfx/hook_whoosh.wav` — старт на `00:00.000`, за 2–3 кадра до первого слова.
- **Пан:** лёгкий стерео-разлёт (L→R), чтобы «в уши».
- **Первые слова** идут поверх хука сразу красивыми субтитрами (секция 2).

```
[SFX] 00:00.000  hook_whoosh.wav   gain -3dB   stereo widen
[CUT] 00:00.000  первый кадр без разгона, сразу в лицо/речь
```

## 2. ПЕРВЫЕ СУБТИТРЫ (красивые, стиль «hook»)

Первые 1–2 фразы — «премиум»-стиль, дальше переключаемся на обычные (секция 4).

### Шрифт и стиль
| Свойство | Значение |
|---|---|
| Шрифт | **TT Norms Pro / Montserrat ExtraBold** *(поставь тот, что юзали — уточни, если помнишь точный)* |
| Размер | 90–110 px, по центру нижней трети |
| Цвет текста | `#FFFFFF` |
| Обводка (stroke) | `#000000`, толщина **2–3 px** — минимально, еле заметно, только чтобы читалось |
| Свечение (glow) | белое `#FFFFFF`, blur 12–18, opacity 60–70% — буквы слегка «светятся» |
| Анимация появления | pop-in по словам (scale 0.85→1.0, 120 мс) |

### Пример настроек (After Effects / CapCut / ASS)
```ass
Style: Hook, TT Norms Pro, 100, &H00FFFFFF, &H000000FF, &H00000000, &H64FFFFFF,
       -1,0,0,0,100,100,0,0, 1, 2.5, 3, 2, 60,60,120, 1
; ↑ Outline 2.5 (тонкая чёрная), Shadow=glow (белый), BorderStyle=1
```

### Звук появления «чик-чик-чик»
- На **каждое всплывающее слово** первых субтитров — короткий клик.
- **Слой SFX:** `sfx/click_tick.wav` (тот самый «чик»), синхрон по кадру появления слова.
```
[SFX] <t_word1>  click_tick.wav
[SFX] <t_word2>  click_tick.wav
[SFX] <t_word3>  click_tick.wav
```

## 5. ПОДСВЕТКА ТЕЛЕФОНА (эффект «ромб + бегущий свет»)

> Тот эффект, когда объект «выделяют в ромбик» и по обводке проходит луч света (scan-line / shine sweep вокруг контура).

- **Момент:** когда в кадре показываешь телефон → `[PHONE]` тайм-код.
- **Как собрать:**
  1. Маска/rotoscope по контуру телефона (или прямоугольник со скруглением, повёрнутый — «ромбик»).
  2. Обводка контура: белая линия 3–4 px + внешнее свечение.
  3. **Shine sweep:** градиентный блик, бегущий по обводке (0→100% за 0.6–0.8 сек), 1–2 прохода.
  4. Лёгкий pop телефона (scale 100→103%) в момент выделения.
- **SFX (опц.):** тонкий «shimmer/ding» на момент подсветки — `sfx/shine.wav`.
```
[PHONE] <t_phone_in> → <t_phone_out>
        outline glow 3px #FFFFFF + shine sweep x2 + scale pop 103%
[SFX]   <t_phone_in>  shine.wav  gain -8dB
```
