# tiktok-editor — авто-графика поверх аватар-видео

Берём ролик с говорящим аватаром (HeyGen и т.п.), а на выходе получаем тот же ролик с графикой в стиле «уголовного дела». Там бумажные заметки на скотче, машинописный текст, красные штампы, полароиды, счётчики, сплит-экран и плёночное зерно. Графика привязана к речи по транскрипту.

```
видео ─► Whisper (слова + таймкоды) ─► Claude: план сцен (JSON) ─► Pexels / генератор картинок ─► Remotion рендер ─► out/<job>.mp4
```

## Быстрый старт

```bash
npm install
pip install faster-whisper
cp settings.example.json settings.json   # впиши ключи
export ANTHROPIC_API_KEY=...             # для разметки сцен
npm run make -- path/to/avatar.mp4 --mode mixed
```

Каждый шаг кешируется в `work/<job>/`:

| файл | что это |
|---|---|
| `transcript.json` | транскрипт с таймкодами слов |
| `plan.json` | план сцен от Claude, **можно править руками** |
| `plan.resolved.json` | план с путями к скачанным картинкам |

Поправил `plan.json` → снова `npm run make -- <то же видео>`: перекачаются только новые картинки, потом рендер.
Флаги: `--force plan` (переразметить), `--force assets` (перекачать картинки), `--no-render`.

Режимы (`--mode`):
- `mixed` — фото + графика (по умолчанию);
- `photos` — в основном фото и сплит-экран, аватар между ними;
- `graphics` — только графика поверх затемнённого аватара, без картинок.

Источник картинок (`--provider`): `pexels` (сток, фото и видео), `fal` (генерация, модель из `settings.fal.model`), `placeholder` (офлайн-заглушки).

Превью и ручная правка шаблонов: `npm run studio`.

## Типы сцен

Контракт — `src/types.ts`. Время в секундах исходного видео.

| type | что на экране |
|---|---|
| `photo` | фото/видео на весь экран, Ken Burns, подпись, красная обводка, штамп |
| `split` | аватар уезжает в рамку на одну сторону, фото на другую |
| `note` | рваный лист с машинописью; `[[слово]]` — замазано чёрным; штамп |
| `quote` | цитата на бумаге |
| `checklist` | пункты с красными крестиками по одному |
| `numbers` | 1–3 карточки со счётчиками |
| `polaroids` | 2–4 полароида с подписями |
| `stamp` | большой красный штамп |
| `label` | плашка внизу поверх аватара (место, имя, дата) |
| `board` | доска расследования с фото и красными нитками (финал) |

## Структура

```
src/            Remotion: Main (аватар + слои), scenes/ (шаблоны), ui/ (бумага, штамп, машинопись, плёнка)
pipeline/       make.ts (оркестратор), transcribe.py, plan.ts (Claude), assets.ts (Pexels/fal), render.ts
public/sfx      whoosh / click / camera / stamp
public/fonts    PT Mono, Oswald (кириллица)
```

## Сеть

Нужен доступ к: `huggingface.co` (модель Whisper, один раз), `api.anthropic.com`, `api.pexels.com`, `images.pexels.com`, `videos.pexels.com`, `fal.run` и `*.fal.media` (если генерация).
