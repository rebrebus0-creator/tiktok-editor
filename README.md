# tiktok-editor

## Модуль `stock_media`

Подбор стоковых видео и фото под текстовый сценарий. Написан как
самостоятельный пакет: зависит только от `requests` и `pydantic`, ничего не
знает про остальной софт и подключается одним импортом.

### Как это работает

```
бриф/сценарий
   ↓  planner       нейронка разбирает текст на сцены и придумывает запросы
список запросов
   ↓  providers     параллельный опрос Pexels / Pixabay / Openverse / YouTube
найденные ассеты
   ↓  ranking       отбор по разрешению, ориентации, длительности, тегам
лучшие ассеты
   ↓  cache         скачивание с дедупликацией по sha256
готовые файлы на диске
```

### Установка

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev,llm]"
cp .env.example .env   # и вписать ключи
```

Ключи бесплатные и получаются за пару минут:
[Pexels](https://www.pexels.com/api/), [Pixabay](https://pixabay.com/api/docs/).
Openverse работает без ключа.

### Использование

```python
from stock_media import StockMediaClient

client = StockMediaClient()
assets = client.collect("Девушка бежит по набережной на рассвете", per_query=2)

for a in assets:
    print(a.local_path, a.score, a.license)
```

Шаги доступны и по отдельности — `client.plan()`, `client.search()`,
`client.download()`, если основному софту нужен контроль на каждом этапе.

Проверить руками, ничего не скачивая:

```bash
stock-media "Девушка бежит по набережной на рассвете" --dry-run
```

### Провайдеры

| Провайдер  | Видео | Фото | Ключ    | Лицензия                  |
|------------|-------|------|---------|---------------------------|
| Pexels     | да    | да   | нужен   | Pexels License            |
| Pixabay    | да    | да   | нужен   | Pixabay Content License   |
| Openverse  | нет   | да   | не нужен| Creative Commons (разная) |
| YouTube    | да    | нет  | не нужен| см. предупреждение ниже   |

Google Images сознательно не подключён: там нет API, скрейпинг ломается
после каждого изменения вёрстки, а права на результаты не определены.
Openverse закрывает ту же потребность легально.

### Про YouTube

Провайдер ищет ролики и вырезает из них фрагменты (`yt-dlp` + ffmpeg,
качается только нужный диапазон, а не весь файл). **Выключен по умолчанию** —
включается через `STOCK_MEDIA_ENABLE_YOUTUBE=1`.

Скачивание с YouTube нарушает Условия использования сервиса, а контент почти
всегда под авторским правом. Для личного монтажа это рабочий вариант; в
коммерческом продукте флаг включается под ответственность того, кто его
включает. Поэтому он и вынесен в отдельный опциональный провайдер — основной
модуль остаётся чистым.

### Планировщик запросов

Если задан `ANTHROPIC_API_KEY`, запросы к стокам придумывает Claude
(`claude-opus-5`): разбирает сценарий на сцены и формулирует конкретные
визуальные запросы на английском — стоки ищут по английскому заметно лучше.
Без ключа включается эвристика на стоп-словах: заметно хуже, но модуль не
падает и тесты не требуют сети.
